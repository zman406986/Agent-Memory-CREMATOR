dsh runs only: the two long shapes from the 2026-11-16 uncapped campaign, after the 12-row table cap was removed (ADR-0060). One run per arm per shape; n = 1, so these are directions, not intervals.

Short SWE-batch runs (SWE-bench-Live lite, SWE-rebench) are removed. The compounded shape is a long dsh session over 36 records + 8 SWE tasks + summary, so it stays.

post-cap · 4 draws
  • True tokens: main prompt + output + ask lane + native compaction.
  • Peak context: the largest prompt in the session.
  • Compactions: completed host compactions.
  • Ask triggers: successful prune-ask exchanges. The vanilla arm mounts no ask lane.
  • Removals: product removal applications. Vanilla loads no product; its host pruner is a separate lane and is not counted here.
  • Cost: DeepSeek official is computed from the measured token split; the other three cards are extrapolations, not invoices. The cost table below carries the method.
  • Solve: the task's named fail-tests, after the run.

Post-cap read. On the two long dsh shapes the product used fewer true tokens and lower peak context, with the same compaction count. It solved the same 36/36, and one fewer SWE task on the compounded shape. The token saving does not become a dollar saving at these rates: the product is cheaper only on GLM 5.3 (extended-36 −2.8%, compounded −2.2%). It is more expensive on DeepSeek (+37.7% / +44.0%), GPT-6.1 Sol (+8.8% / +6.8%) and Claude Opus 5.5 (+7.6% / +6.1%), because its ask lane is uncached and output-heavy.
